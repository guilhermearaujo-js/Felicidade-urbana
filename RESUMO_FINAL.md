## 📱 COMO USAR NO CELULAR

### 🚀 Instalação
1. **Acesse** o jogo no navegador do celular
2. **Toque no menu** do navegador
3. **Selecione** "Adicionar à tela inicial"
4. **Confirme** a instalação
5. **Jogue** como um app nativo!

### 🎮 Controles
- **← →** (esquerda): Movimento de Apollo
- **PULAR** (direita superior): Fazer Apollo pular
- **ATACAR** (direita inferior): Apollo atacar inimigos

### 💡 Dicas Mobile
- Use orientação **landscape** (horizontal)
- **Toque e segure** para movimento contínuo
- **Feche outros apps** para melhor performance
- **Conecte o carregador** para sessões longas
