# 📱 Caminho da Fé - Guia Mobile

## 🎮 Jogue no Seu Celular!

O jogo "Caminho da Fé" foi **completamente otimizado** para dispositivos móveis! Agora você pode experimentar a jornada espiritual de Apollo diretamente no seu celular ou tablet com controles touch nativos e gráficos inspirados em Alto's Odyssey.

---

## 🚀 Como Instalar no Celular

### 📱 Android
1. **Abra** o link do jogo no Chrome ou Firefox
2. **Toque no menu** (3 pontos) do navegador
3. **Selecione** "Adicionar à tela inicial"
4. **Confirme** a instalação
5. **Encontre o ícone** na tela inicial
6. **Toque para jogar** como um app nativo!

### 🍎 iPhone/iPad
1. **Abra** o link do jogo no Safari
2. **Toque no ícone** de compartilhamento (caixa com seta)
3. **Role para baixo** e toque em "Adicionar à Tela de Início"
4. **Edite o nome** se desejar
5. **Toque em Adicionar**
6. **Encontre o app** na tela inicial
7. **Abra e jogue** em tela cheia!

## 🎮 Controles Touch

### 🕹️ Layout dos Controles
```
Tela do Jogo:
┌─────────────────────────────────────┐
│  [VIDA] [FÉ] [PONTOS]              │
│                                     │
│     🎮 ÁREA DE JOGO 🎮             │
│                                     │
│  [←] [→]               [PULAR]     │
│                        [ATACAR]    │
└─────────────────────────────────────┘
```

### 📍 Localização dos Botões
- **Movimento**: Inferior esquerdo
  - **← (Esquerda)**: Move Apollo para a esquerda
  - **→ (Direita)**: Move Apollo para a direita
  
- **Ações**: Inferior direito
  - **PULAR**: Botão superior - Faz Apollo pular
  - **ATACAR**: Botão inferior - Apollo ataca inimigos

### 💡 Como Usar
- **Toque e segure** para movimento contínuo
- **Toque rápido** para ações pontuais
- **Mantenha pressionado** o botão de movimento para correr
- **Toque PULAR** apenas quando no chão
- **Use ATACAR** quando próximo de inimigos

## ❓ Solução de Problemas Mobile

### 🔧 Problemas Comuns

**🐛 Controles não respondem:**
- Recarregue a página
- Verifique se JavaScript está ativado
- Tente outro navegador

**🐛 Jogo lento ou travando:**
- Feche outros apps
- Reinicie o navegador
- Verifique espaço disponível

**🐛 Não consigo instalar:**
- Use o navegador nativo (Safari/Chrome)
- Verifique se PWA é suportado
- Tente modo incógnito primeiro

**🐛 Tela pequena demais:**
- Gire para landscape
- Remova zoom (pinch out)
- Recarregue a página

### 🆘 Suporte
Se tiver problemas:
1. **Tente primeiro** as soluções acima
2. **Teste em modo incógnito**
3. **Verifique atualizações** do navegador
4. **Reinicie o dispositivo** se necessário
