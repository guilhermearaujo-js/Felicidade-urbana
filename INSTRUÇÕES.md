# Instruções - Caminho da Fé

## 📱 Jogo Otimizado para Mobile!

O jogo "Caminho da Fé" agora funciona perfeitamente no seu celular e tablet! Experimente uma experiência de jogo premium inspirada em Alto's Odyssey diretamente no seu dispositivo móvel.

## 🚀 Como Executar

### 📱 No Celular/Tablet
1. **Acesse** o link do jogo no navegador do seu celular
2. **Adicione à tela inicial** para experiência de app nativo:
   - **Android**: Menu → "Adicionar à tela inicial"
   - **iOS**: Compartilhar → "Adicionar à Tela de Início"
3. **Jogue** diretamente da tela inicial como um app!

### 💻 No Computador
#### Opção 1: Servidor Local (Recomendado)
```bash
# No terminal, dentro da pasta do jogo:
python3 -m http.server 8000
```
Depois acesse: `http://localhost:8000`

#### Opção 2: Abrir Diretamente
- Abra o arquivo `index.html` em qualquer navegador moderno
- Funciona com Chrome, Firefox, Safari, Edge

## 🎮 Controles do Jogo

### 📱 Controles Mobile (Touch)
O jogo detecta automaticamente dispositivos móveis e exibe controles touch otimizados:

| Controle | Localização | Ação |
|----------|-------------|------|
| **←** | Inferior esquerdo | Mover Apollo para esquerda |
| **→** | Inferior esquerdo | Mover Apollo para direita |
| **PULAR** | Inferior direito (superior) | Fazer Apollo pular |
| **ATACAR** | Inferior direito (inferior) | Apollo atacar inimigos |

### ⌨️ Controles Desktop (Teclado)
| Tecla | Ação |
|-------|------|
| **← →** | Mover Apollo |
| **Espaço** | Pular |
| **Enter** | Atacar |

## 🎯 Dicas de Jogo

### 📱 Dicas Específicas para Mobile
1. **Segure firme o dispositivo** - Os controles respondem ao toque
2. **Use landscape** - Gire o celular para melhor experiência
3. **Toque e segure** para movimento contínuo
4. **Toque rápido** para ações pontuais
5. **Evite tocar fora dos botões** para não interferir no jogo

### 🎮 Dicas Gerais
1. **Colete todas as Pedras de Fé** de cada nível para progredir
2. **Evite ou derrote os inimigos** - eles diminuem sua vida e fé
3. **Encontre os anjos** nos níveis 3 e 5 para recuperar vida e fé
4. **Mantenha sua fé alta** - com fé >80%, Apollo ganha uma auréola
5. **Use as plataformas** para navegar pelos níveis

## 🌟 Elementos do Jogo

- 🟦 **Pedras de Fé**: Colete para progredir (brilham em azul)

## 📱 Recursos Mobile

### ✨ Progressive Web App (PWA)
- **Instale como app nativo** na tela inicial
- **Funciona offline** após primeira carga
- **Tela cheia** sem barras do navegador
- **Orientação landscape** otimizada

### 🎨 Interface Responsiva
- **Controles touch** nativos e responsivos
- **Tamanhos adaptativos** para diferentes telas
- **Interface otimizada** para celular e tablet
- **Feedback visual** nos toques

### ⚡ Performance Otimizada
- **Menos partículas** no mobile para melhor performance
- **Canvas responsivo** que se adapta ao tamanho da tela
- **Prevenção de zoom** indesejado
- **Smooth scrolling** desabilitado durante o jogo
